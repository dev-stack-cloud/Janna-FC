# Janna Football Academy

Janna Football Academy is a simple responsive landing page for a fictional youth football academy in Ras Al Khaimah.

> **Important:** This is not a real product, company, academy, or commercial website.
> The project was created only as a demo / practice portfolio project.

## About the Project

The website presents a clean one-page layout for a football training academy for kids aged 7–14.
It includes basic sections that a small local business website usually needs: introduction, programs, coach information, schedule, pricing, and contact button.



## Technologies Used

* HTML
* CSS
* JavaScript



## Note

All names, content, prices, coach details, and contact information are fictional or used for demonstration purposes only.
This website is not connected to any real football academy or business.

## Purpose

This project was created to practice building modern landing pages and to be used as a portfolio example for web development.
